# Phase 2 前置條件簽核任務包 v1

> 文件狀態：Draft v1 可簽核  
> 角色定位：PMO Governance Architect  
> 適用範圍：Phase 2 前置條件 G-01 ~ G-06

---

## 1. 簽核通過定義 Definition of Done

Phase 2 進場前，以下條件必須同時成立：

1. G-01 ~ G-06 皆完成決策紀錄，且 `Decision` 欄位不得為空。  
2. 每一項議題均指定單一 `Responsible` 與單一 `Approver`，並與 RACI 一致。  
3. 每一項議題均提交最低證據包，證據可回查 `trace_id` 或版本編號或審批編號。  
4. 涉及數值門檻但尚未核定者，必須明示 `待簽核`，不得以草案值宣告正式承諾。  
5. 任何標記為「不決不可進 Phase 2」之議題，若未完成簽核，Phase 2 不得啟動。

---

## 2. 升級路徑 逾期處置

### 2.1 逾期判定

- 以各議題 `截止日期 T+N` 為判定基準。  
- 逾期定義：超過 T+N 仍無簽核結論，或證據包不完整且未於同日補齊。

### 2.2 升級機制

| 逾期情境 | 升級等級 | 升級路徑 | 強制處置 |
|---|---|---|---|
| 單一議題逾期未結論 | P2 | Responsible -> PM -> SA | 24x7 口徑內補開決策會，限制變更進場 |
| 涉及法遵或審計保留風險逾期 | P1 | SC 值班 -> PM -> 管理層 | 先行風險隔離，凍結相關上線與資料處置 |
| 兩項以上阻斷議題同時逾期 | P1 | PM -> 管理層 -> 聯合 Approver | 啟動 Phase 2 Gate Hold，僅允許修復性工作 |

> 升級時限沿用治理基線：P1 首次回應 30 分鐘、正式決策 8 小時；P2 首次回應 2 小時、正式決策 24 小時。

## 4. G-01 資料字典與標籤治理定版

### 4.1 議題背景與風險說明

- 目前欄位模板、標籤事件定義、觀測窗預測窗與部分枚舉值仍屬草案。  
- 若未定版即進入 Phase 2，將產生標籤洩漏、資料切分失真、跨系統 schema 不一致風險。

### 4.2 決策選項

| 選項 | 說明 | 主要風險 |
|---|---|---|
| A | 先凍結資料字典與標籤模板，全部未定欄位保留待簽核標記後進場 | 需承擔後續欄位調整成本 |
| B | 僅凍結 Must Gate 欄位與標籤時序規則，其餘延後 | 後續跨團隊解讀落差較大 |
| C | 先執行小範圍試跑再定版 | 時程延後，治理簽核節奏複雜 |

### 4.3 建議方案與理由

- 建議採 **選項 A**。  
- 理由：可確保 API 契約、資料品質 Gate、標籤規則同源管理，並維持未定數值以 `待簽核` 明示，避免誤承諾。

### 4.4 影響分析

| 面向 | 影響 |
|---|---|
| 合規 | 降低標籤定義爭議與取證不可重現風險 |
| 效能 | 對效能直接影響低，間接降低資料反覆清洗成本 |
| 可維運 | 提升 schema 變更治理可追溯性 |
| 時程 | 初期會議工作增加，但可降低 Phase 2 返工 |

### 4.5 責任與期限

- Responsible：DE  
- Approver：CA  
- 截止日期：T+5

### 4.6 證據欄位

1. 欄位對照清單 模板欄位對真實欄位映射。  
2. 標籤定義簽核單 含事件條件與時間窗。  
3. 標籤一致性抽測報告 含病人隔離與時序檢核。

## 5. G-02 審計事件與保留政策定版

### 5.1 議題背景與風險說明

- 審計保留期、刪除權限角色、取證封裝格式與簽章強度仍有待確認項。  
- 若直接進場，可能出現保留違規、證據不可採信、權限邊界模糊風險。

### 5.2 決策選項

| 選項 | 說明 | 主要風險 |
|---|---|---|
| A | 採 online 180 天與 archive 2 年建議值，標示待簽核後先行治理 | 若法遵要求更長，需補強遷移策略 |
| B | 僅先核定事件必記錄清單，保留期延後 | 可能影響取證完整性與刪除流程設計 |
| C | 全量待法遵最終簽核後再啟動 | 風險最低但 Gate 時程壓力較大 |

### 5.3 建議方案與理由

- 建議採 **選項 A**。  
- 理由：兼顧可執行性與合規控制，並明示 `180 天` 與 `2 年` 為 `待簽核`，不宣告最終結論。

### 5.4 影響分析

| 面向 | 影響 |
|---|---|
| 合規 | 建立最小可稽核基線，保留正式法遵簽核空間 |
| 效能 | 審計寫入策略需維持主路徑最小阻塞 |
| 可維運 | 事件字典與保留分層更一致 |
| 時程 | 可先進行驗證，後續補正式法遵核章 |

### 5.5 責任與期限

- Responsible：MOP  
- Approver：SC  
- 截止日期：T+4

### 5.6 證據欄位

## 6. G-03 延遲預算與量測口徑定版

### 6.1 議題背景與風險說明

- 現行基線為 E2E P95 小於 500ms 與 S1~S7 分段預算，但冷啟容忍、尖峰恢復、S7 審計時序尚待確認。  
- 若口徑不一致，將造成驗收數據不可比較與告警誤判。

### 6.2 決策選項

| 選項 | 說明 | 主要風險 |
|---|---|---|
| A | 以 SCN-01 為主驗收口徑，固定 E2E P95 小於 500ms，其他為輔助監控 | 對特殊場景彈性較低 |
| B | 依端點分流口徑，各自定義門檻 | 管理複雜度高，跨團隊認知成本高 |
| C | 先以 P95 建議值運行觀察後再定版 | 會議後決策延遲，Gate 風險升高 |

### 6.3 建議方案與理由

- 建議採 **選項 A**。  
- 理由：與現有驗收主敘述一致，且 S1~S7 可保留分段治理；冷啟與尖峰恢復數值以 `待簽核` 註記。

### 6.4 影響分析

| 面向 | 影響 |
|---|---|
| 合規 | 量測可追溯，有助事故稽核 |
| 效能 | 可快速定位瓶頸段並維持主門檻一致 |
| 可維運 | 告警與復盤口徑統一 |
| 時程 | 減少驗收爭議，利於 Phase 2 排程 |

### 6.5 責任與期限

- Responsible：BE  
- Approver：MOP  
- 截止日期：T+3

### 6.6 證據欄位

1. SCN-01 至 SCN-05 測試報告 含 P50 P95 P99。  
2. S1~S7 分段延遲與告警樣本。

## 7. G-04 安全與隱私控制基線定版

### 7.1 議題背景與風險說明

- STRIDE 威脅清單與控制策略已建立，但金鑰輪替週期、精確分數保存、下載連結時效仍待簽核。  
- 若控制與例外未定義清楚，可能導致個資暴露與法遵升級事件。

### 7.2 決策選項

| 選項 | 說明 | 主要風險 |
|---|---|---|
| A | 採最小揭露與白名單控制為預設，所有例外需獨立審批 | 例外申請流程較多 |
| B | 先開放部分精確資料保存，事後補治理 | 法遵與隱私風險偏高 |
| C | 僅落地威脅高風險控制，其他延後 | 中低風險項累積成治理缺口 |

### 7.3 建議方案與理由

- 建議採 **選項 A**。  
- 理由：與審計不可否認性和資料最小化一致，且可將輪替週期 `90 天`、RTO RPO、下載連結時效明示為 `待簽核`。

### 7.4 影響分析

| 面向 | 影響 |
|---|---|
| 合規 | 降低敏感資料與密鑰治理違規機率 |
| 效能 | 需平衡安全檢核與延遲，避免阻塞主路徑 |
| 可維運 | 安全事件可與告警工單閉環 |
| 時程 | 初期治理工作量上升，但降低後續事故成本 |

### 7.5 責任與期限

- Responsible：SC  
- Approver：PM  
- 截止日期：T+4

### 7.6 證據欄位

1. 威脅模型控制對照表 含 T01~T12。  
2. 去敏抽驗報告與觀測欄位白名單稽核。  
3. 秘密掃描與密鑰輪替審批紀錄。

## 8. G-05 NFR 驗收門檻定版

### 8.1 議題背景與風險說明

- NFR 多項門檻仍屬建議值，包含成功率 99.5%、非同步完成率 99%、Runbook 覆蓋率 90% 等。  
- 若未先定義簽核規則，Phase 2 驗收可能出現標準漂移。

### 8.2 決策選項

| 選項 | 說明 | 主要風險 |
|---|---|---|
| A | 將建議值作為簽核候選門檻，逐項標記待簽核後定版 | 需跨角色一次性收斂 |
| B | 僅定義 Must，Should 全部延後 | 優化與成熟度目標易失焦 |
| C | 先以歷史觀察值取代門檻 | 缺少治理約束，難以驗收 |

### 8.3 建議方案與理由

- 建議採 **選項 A**。  
- 理由：兼顧可驗收與可演進，並可在會議中逐項確認哪些門檻保持 `待簽核`。

### 8.4 影響分析

| 面向 | 影響 |
|---|---|
| 合規 | 可審計性與隱私門檻可被量化稽核 |
| 效能 | 與延遲治理門檻一致，避免雙軌口徑 |
| 可維運 | Runbook 與告警品質可形成閉環 |
| 時程 | 前置對齊成本上升，但可降低驗收爭議 |

### 8.5 責任與期限

- Responsible：QA  
- Approver：PM  
- 截止日期：T+5

2. 量測證據包 延遲 可用性 可靠性 可審計性。
