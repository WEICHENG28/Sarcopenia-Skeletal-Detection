# 即時錄影引導驗證

## 動作與停止方式

- 起立坐下：從坐姿開始計算 5 次起立，達標後延遲 1.5 秒停止；至少計到 1 次後若靜止 4 秒，也會提示並延遲停止。操作者可隨時手動停止。
- 行走：走完三公尺後手動停止。準備移動、等待口令或中途停頓不會觸發自動停止。
- 半蹲：偵測到蹲下並維持 3 秒後提示完成，由操作者手動停止，不要求做 5 次。中途起身、離開畫面或骨架不可用會重新計算維持時間。
- 即時模型載入或推論失敗時，仍可手動錄影、停止並上傳。

提示以相機中的髖部相對位移估計，不代表經過驗證的動作量測。實際收案仍由操作者確認動作完成。

## 自動測試

```bash
pytest tests/ -q
node --test tests/recording.test.cjs
```

前端測試執行實際頁面的 JavaScript，使用模擬骨架、MediaRecorder、計時器及上傳端點，涵蓋計次、半蹲維持、行走準備、跨錄影計時器、影片資料隔離和姿勢模組失敗。GitHub Actions 同時執行 Python 與前端測試。

## 真人鏡頭驗證（尚待執行）

自動測試不能驗證實體攝影機、CDN 模型載入、語音或真實人體辨識準確度。請在實際使用的瀏覽器開啟 `http://localhost:8000`，記錄瀏覽器版本及結果：

- [ ] MediaPipe 模組、WASM 與模型正常載入，骨架疊圖與身體位置一致。
- [ ] 從坐姿做 5 次起立，確認第一下有計入，達標停止後影片可上傳。
- [ ] 半蹲維持 3 秒只提示完成，不要求重複 5 次；未滿 3 秒起身或離開畫面不應完成。
- [ ] 行走前調整站位、等待口令及中途停頓均不會提前結束，手動停止後影片可上傳。
- [ ] 自動停止倒數時手動停止，立即錄製下一項或重錄同項，新錄影不受前段計時器影響。
- [ ] 關閉語音提示後不再播報；開啟後口令可聽見。
- [ ] 封鎖 MediaPipe CDN／模型請求並重新整理，仍可手動錄影、保存和上傳。

此清單尚未以真人及實體鏡頭完成；CI 綠燈不代表以上項目已驗證。
