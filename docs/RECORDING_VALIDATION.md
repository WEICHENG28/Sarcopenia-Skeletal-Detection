# 展場錄影與動作引導驗證

## 動作與停止方式

- 起立坐下：確認受測者穩定坐好後才倒數；從坐姿開始計算 5 次起立，達標後自動停止。60 秒內未完成會停止並要求工作人員協助或重錄。
- 行走：確認受測者在起點穩定站好後才倒數；偵測髖部到達穩定終點後自動停止，30 秒未到達則停止並要求協助。
- 半蹲：確認受測者穩定站好後才倒數；錄製一次半蹲共 4 秒後自動停止，不要求重複 5 次。
- 每一項都先檢查肩、髖、膝與至少一側腳踝完整入鏡；12 秒仍無法自動判定時，工作人員可明確按下「確認已就緒」，不會悄悄略過。
- C922 的預覽與錄影由電腦端 FastAPI 管理；凱比只負責顯示流程、播放語音與接收操作，不直接存取 USB 攝影機。

姿勢與位移提示是展場流程控制，不代表經臨床驗證的動作量測，也不是診斷。實際收案仍由工作人員監看安全並確認流程。

## 自動測試

```bash
pytest tests/ -q
node --test tests/action_readiness.test.js tests/sit_to_stand_counter.test.js
```

Node 測試驗證三項動作的就緒門檻、離框重設、工作人員明確備援，以及五次起立坐下的坐姿校正、遮擋復原與穩定幀計次。Python 測試驗證自動狀態機、C922 錄影端點、QR／名冊、語音、控制頁與展場啟動前檢查。GitHub Actions 同時執行兩類測試。

## 真人鏡頭驗證（尚待執行）

自動測試不能驗證實體攝影機、場地距離、音量或真實人體辨識準確度。請依 `docs/EXHIBITION_RUNBOOK.md` 在實際展場完成：

- [ ] MediaPipe 模組、WASM 與模型正常載入，骨架疊圖與身體位置一致。
- [ ] `/exhibition/preflight` 回報 `ready: true`，C922 畫面、名冊、模型、前端模組及 28 個語音檔均通過。
- [ ] 從坐姿做 5 次起立，確認第一下有計入，達標後自動停止且影片可分析。
- [ ] 行走在實際三公尺標線完成後才停止；站位調整與等待口令不應提前結束。
- [ ] 半蹲只錄一次 4 秒，不要求重複 5 次，結束後自動進入分析。
- [ ] 語音口令在展場噪音下仍清楚；Firefox 首次開啟時可以正常完成音訊解鎖。
- [ ] 任一動作無法自動判定就緒時，工作人員按下備援確認後可以繼續，不會讓流程卡死。

此清單仍需以真人、椅子、三公尺標線與展場音量完成；CI 綠燈和單張 C922 畫面不等於完整真人流程已驗證。
